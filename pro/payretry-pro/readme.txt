Revenue recovery reports for PayRetry: recovered orders, recovered revenue and recovery rate for your failed-payment reminders.

== Description ==

PayRetry Pro is an add-on for the PayRetry plugin. It shows how much money your failed-payment recovery emails actually earn:

* Failed payments with reminders sent
* Recovered orders (orders that came back using a RECOVER-* coupon)
* Recovered revenue and recovery rate
* Recent recovered orders list

Requires the free PayRetry plugin to be installed and active.

== Installation ==

1. Install the free PayRetry plugin and activate it.
1. Upload the payretry-pro folder to wp-content/plugins/ (or install the zip via Plugins → Add New → Upload).
1. Activate "PayRetry Pro".
1. Open WooCommerce → PayRetry Pro.
